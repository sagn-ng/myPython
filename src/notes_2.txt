There are four collection data types in the Python programming language:

List is a collection which is ordered and changeable. Allows duplicate members.
Tuple is a collection which is ordered and unchangeable. Allows duplicate members.
Set is a collection which is unordered, unchangeable*, and unindexed. No duplicate members.
Dictionary is a collection which is ordered** and changeable. No duplicate members.

* List:
- A list is created using square brackets "[]"
    List is the same as
    +   ordered (unchangeable generally)
    +   0-indexed
    +   contains changeable elements
    +   allows duplicates

    A list can contain any different data type

- Print a list, e.g: print(myList)
- Accessing items work the same as in string
- Changing a range of items is available, not only changing single ones
- Adding items: append(itemName); insert(idx, itemName)
- Removing items: remove(itemName); pop(idx) (last item by defalut);
- Clear a list: clear() method
- List comprehension:  listName = [<expression> for <item> in <iterable> if <condition>]
- Sort: sort()
- Copy: copy()
- Join: append(), '+', '[:]'

* Tuple:
- A tuple is created using curly brackets (optional) "()"
A tuple is a collection which is ordered and unchangeable.
    + 0-indexed, ordered, unchangeable, allows duplicates.

- Items in a tuple are accessed by their indices (the same as in a list)
- A tuple is immutable (cannot change its values and size)
- When creating a tuple, we assign values to it -> packing. We're allowed to extract those
values into variables -> unpacking. (notice about the "*" case)
- Join tuples: use '+' or "*" for multiplying

* Set:
- create a set with {}, or the set() constructor
A set is a collection which is unordered, unchangeable (cannot change items' values), and unindexed.
When printing a set, cannot sure in which order elements will be printed

- Add: add()
- Remove: remove() or discard()
- Join sets: union(), difference(), intersection(),...
- Copy a set: copy()
- Clear: clear()

- frozenset: an immutable version of a set: cannot add or remove elements

* Dictionary: a dictionary stores items by key-value pairs
A dictionary is a collection which is ordered*, changeable and does not allow duplicates.
- Create a dictionary: use the {}, e.g:
    thisdict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
    }
    print(thisdict)

- Access items by their keys, with '[]' or the get() method
Extract the key set: keys() method; extract the value set: values() method;
extract both (as tuples) in a list: items() method()

- Update a key's value or add a new item: directly refer to that value with '[]', or use the
update() method

- Remove an item (by its key): use the pop() method
    (the popitem() method removes the last inserted item)

- Copy a dictionary: copy()

- Clear the dictionary: clear()
